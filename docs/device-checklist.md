# スマホの実機検証

試作で撮った写真は、従来の撮影方法と併用して確認してください。

- [ ] HTTPSの配布先を開き、ホーム画面に追加して起動できる。
- [ ] 地点を追加・編集・削除し、再起動しても設定が残る。
- [ ] カメラ撮影できる。キャンセルしても再び撮影できる。
- [ ] 写真取り込み（JPEG、端末で使うHEIC等）で成功または明確なエラーになる。
- [ ] 横・縦写真の向きが正しく、黒板の4隅・サイズ・2デザイン・日時3モードが反映される。
- [ ] 12MP程度の写真で細かな計器の文字を読める。画像寸法、保存所要時間も記録する。
- [ ] 原本と合成画像を保存し、アプリを閉じて再起動しても両方を書き出せる。
- [ ] 合成写真の共有から「画像を保存」等で写真アプリに入り、実際の画像を開ける。
- [ ] 一式をファイルへ共有、または3ファイルを個別ダウンロードし、PC側で名前と内容が一致する。
- [ ] 2端末から同じ地点・同じ項目を撮ってもファイル名が衝突しない。
- [ ] オフライン準備完了後に機内モードにして、アプリを再起動し、地点選択・撮影・保存できる。
- [ ] 保存容量が少ない時の失敗を確認し、成功していないのに保存完了と出ない。削除・書き出し後に再試行できる。
- [ ] 原本のEXIFと合成JPEGの差を確認し、提出先に原本＋合成写真の扱いを確認する。

ブラウザの保存領域はバックアップではありません。写真アプリやPCへ書き出した後、保存先で画像を開いて確認してください。共有画面を閉じただけでは保存先での完了をアプリから判定できません。
