# スマホの実機検証

試作で撮った写真は、従来の撮影方法と併用して確認してください。

- [ ] HTTPSの配布先を開き、ホーム画面に追加して起動できる。
- [ ] 地点を追加・編集・削除し、再起動しても設定が残る。
- [ ] カメラ撮影できる。キャンセルしても再び撮影できる。
- [ ] ライブカメラで黒板が見え、四隅・サイズ・2デザインの変更が撮影前と保存写真で一致する。縦横を回転しても被写体の位置がずれない。
- [ ] 全画面撮影中にスワイプしてもページが上下へ動かない。縦・横のどちらでも矢印・＋−・撮影・閉じるボタンが見える。
- [ ] 矢印で黒板を少しずつ移動でき、連続して押しても画像外へはみ出さない。＋−で拡縮してから撮影しても位置が一致する。
- [ ] 黒板をタップして地点名・工種・写真項目・日時を編集できる。キーボード表示中も反映／キャンセルでき、編集画面を閉じるとカメラへ戻れる。キャンセル時には変更されない。
- [ ] 写真の保存後、再起動しても黒板の位置・大きさが残る。過去の保存写真は地点名を変更しても変わらない。
- [ ] ライブ撮影の実寸法が表示され、保存後の画像寸法と一致する。標準カメラと細かな計器の文字の読みやすさを比較する。
- [ ] 撮影後・別画面・ホーム画面へ移った際にカメラ使用表示が消える。カメラ許可拒否後も標準カメラ／写真選択で使える。
- [ ] 写真取り込み（JPEG、端末で使うHEIC等）で成功または明確なエラーになる。
- [ ] 横・縦写真の向きが正しく、黒板の4隅・サイズ・2デザイン・日時3モードが反映される。
- [ ] 12MP程度の写真で細かな計器の文字を読める。画像寸法、保存所要時間も記録する。
- [ ] 原本と合成画像を保存し、アプリを閉じて再起動しても両方を書き出せる。
- [ ] 合成写真の共有から「画像を保存」等で写真アプリに入り、実際の画像を開ける。
- [ ] 一式をファイルへ共有、または3ファイルを個別ダウンロードし、PC側で名前と内容が一致する。
- [ ] 地点ごとのZIPとその日全部のZIPを作り、対象の地点・日付・枚数だけが入る。他の日の写真が混ざらない。
- [ ] iPhoneの「ZIPを保存」／「ZIPを共有」からファイルへ保存できる。Windowsへ渡して標準の「すべて展開」で日本語フォルダ名と画像が正しく開ける。
- [ ] ZIP内に黒板付き写真・原本・管理JSON・書き出し一覧が揃い、PCで原本も開ける。ZIPを作った後もアプリ内の写真は残る。
- [ ] 機内モードでZIPを作成できる。大量の写真では地点単位に分け、端末の保存容量に収まる。
- [ ] 「仕分け用データを確認」と書き出したJSONで地点・工種・項目・日時が一致する。画像のみの共有と管理データの書き出しの違いが分かる。
- [ ] 2端末から同じ地点・同じ項目を撮ってもファイル名が衝突しない。
- [ ] オフライン準備完了後に機内モードにして、アプリを再起動し、地点選択・撮影・保存できる。
- [ ] 保存容量が少ない時の失敗を確認し、成功していないのに保存完了と出ない。削除・書き出し後に再試行できる。
- [ ] 原本のEXIFと合成JPEGの差を確認し、提出先に原本＋合成写真の扱いを確認する。

ブラウザの保存領域はバックアップではありません。写真アプリやPCへ書き出した後、保存先で画像を開いて確認してください。共有画面を閉じただけでは保存先での完了をアプリから判定できません。
